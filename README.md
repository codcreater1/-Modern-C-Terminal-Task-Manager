# Modern C++ Terminal Task Manager

A single-file, modern C++20 terminal-based task manager with colorful UI and persistent storage.

Perfect for showcasing clean code, modern C++ features, and CLI application development in your portfolio.

## Features

- Add tasks with optional priority (low/medium/high)
- List all tasks with color-coded status and priority
- Mark tasks as completed
- Delete tasks
- Search tasks by keyword
- Data persistence using `tasks.txt`
- Clean, colorful terminal interface using ANSI codes
- No external dependencies

## Compilation & Run

```bash
g++ -std=c++20 main.cpp -o taskmanager
./taskmanager
